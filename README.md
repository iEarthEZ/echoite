# Echoite

INTRODUCING A BRAND NEW ORE TO MINECRAFT! The ECHOITE (pronounced AE-KO-ITE) is a twist to add to your minecraft world. It has its ups and downs! It is similar to the iron but more powerful in its abilities. The durability is as similar to the existing iron, BUT the overpowerness reaches up to netherite! It also gives you strength 2 and regeneration 3 effects as long as you wear the full set of armor! The tools on the other hand has less cooldown and more damage than regular tools!

I hope y'all enjoy the mod as this was my one of the very first experience of coding especially in java and i pray that i did a good job!
